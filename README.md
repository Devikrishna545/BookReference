# 📚 BookReference

A curated collection of essential computer science and machine learning textbooks for reference and study.

## 📖 Books Included

### Artificial Intelligence
- **Artificial Intelligence - A Modern Approach (3rd Edition).pdf**
  - Comprehensive textbook covering fundamental AI concepts and techniques
  - Topics include intelligent agents, search algorithms, knowledge representation, planning, and more

### Machine Learning
- **Hands On Machine Learning with Scikit Learn and TensorFlow.pdf**
  - Practical guide to machine learning using popular Python libraries
  - Covers supervised and unsupervised learning, neural networks, and deep learning

- **mml-book.pdf** (Mathematics for Machine Learning)
  - Mathematical foundations for machine learning
  - Linear algebra, probability theory, and optimization techniques

### Data Structures & Algorithms
- **Data Structures and Algorithms - Narasimha Karumanchi-compressed.pdf**
  - Comprehensive guide to data structures and algorithms
  - Problem-solving approaches and interview preparation

- **Data Structures and Algorithms with Python.pdf**
  - Python-specific implementation of data structures and algorithms
  - Practical examples and code implementations

- **Grokking Algorithms - An illustrated guide for programmers and other curious people.pdf**
  - Visual and beginner-friendly approach to algorithms
  - Illustrated explanations of common algorithms and problem-solving techniques

## 🎯 Purpose

This repository serves as a reference library for:
- Computer science students
- Software engineers preparing for technical interviews
- Machine learning practitioners
- Anyone interested in AI and algorithms
